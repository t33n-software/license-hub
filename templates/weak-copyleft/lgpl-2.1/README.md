# LGPL-2.1 template

- Template: `LGPL-2.1-1.0.0.hbs` (version 1.0.0)
- License family: `templates/weak-copyleft` — canonical family documentation: [docs/licensing/weak-copyleft/README.md](../../../docs/licensing/weak-copyleft/README.md)
- License identity: `LGPL-2.1-only or LGPL-2.1-or-later`
- Canonical template documentation: [lgpl.md](../../../docs/licensing/weak-copyleft/lgpl.md)

Template bodies never carry comments: rendering is pure placeholder
substitution, so any comment would be emitted into the rendered legal text of
every tenant. This README is the documentation seam of the template directory;
the legal SemVer history lives in `CHANGELOG.md`.
