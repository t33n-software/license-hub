# JSON License (`JSON`)

Family: B — Source-Available, group B4 (Values-Restricted). **Not
OSI-approved open source.** Canon: [license taxonomy canon](../README.md);
family reference: [source-available README](README.md).

- Template: [`templates/source-available/json/JSON-1.0.0.hbs`](../../../templates/source-available/json/JSON-1.0.0.hbs)
- Steward/status: JSON.org; the MIT text plus the "Good, not Evil" clause —
  famously the license that required an IBM "evil-use" exemption letter.

## Grant, conditions, restrictions

- Grant: the MIT-style grant — use, copy, modify, merge, publish, distribute,
  sublicense, and sell, free of charge.
- Conditions: the copyright notice and the permission notice must be included
  in all copies or substantial portions.
- Restrictions: "The Software shall be used for Good, not Evil." — a
  values restriction that removes the text from the open-source space.

## Patent position

No grant.

## Compliance classification

Proprietary-grade: the values clause fails the OSD and many corporate
policies; legal review before adoption.

## Adoption

Set `SPDX_LICENSE_IDENTIFIER` to `JSON`. The template body is byte-identical
to the canonical text; the steward document copyright line ("Copyright (c)
2002 JSON.org") is part of the canonical license document and stays verbatim —
the tenant's own copyright is carried by the per-file source headers.
