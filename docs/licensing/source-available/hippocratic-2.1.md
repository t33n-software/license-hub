# Hippocratic License 2.1 (`Hippocratic-2.1`)

Family: B — Source-Available, group B4 (Ethical / Values-Restricted). **Not
OSI-approved open source** — the ethics restrictions are OSD-incompatible by
design. Canon: [license taxonomy canon](../README.md); family reference:
[source-available README](README.md).

- Template: [`templates/source-available/hippocratic-2.1/Hippocratic-2.1-1.0.0.hbs`](../../../templates/source-available/hippocratic-2.1/Hippocratic-2.1-1.0.0.hbs)
- Steward/status: Ethical Source movement; version 2.1 is the current steward
  text.

## Grant, conditions, restrictions

- Grant: broad permission to use and work with the software within the
  licensor's copyright and patent rights, free of charge.
- Conditions: notice retention; modified versions carry prominent change
  notices; a 30-day cure path for notice non-compliance.
- Restrictions: the software must not be used for systems, activities, or
  other uses that violate human-rights laws, with arbitration through the
  Hague Rules on Business and Human Rights Arbitration and an indemnity
  clause.

## Patent position

Express permission to the extent of the licensor's patent rights; no
retaliation clause.

## Compliance classification

Proprietary-grade plus ethics-axis legal review: the enforceability of
values-restricted clauses is largely untested — state this residual
uncertainty when recommending.

## Adoption

Set `SPDX_LICENSE_IDENTIFIER` to `Hippocratic-2.1`. The template anchors the
licensor line to the `PROJECT_NAME`, `COPYRIGHT_YEAR`, and
`COPYRIGHT_HOLDER` anchors; the rest of the text is byte-identical to the
canonical text.
