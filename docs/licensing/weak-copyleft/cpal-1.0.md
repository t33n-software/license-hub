# Common Public Attribution License 1.0 (`CPAL-1.0`)

Family: A — Open Source, weak copyleft (A2). Canon:
[license taxonomy canon](../README.md); family reference:
[weak-copyleft README](README.md).

- Template: [`templates/weak-copyleft/cpal-1.0/CPAL-1.0-1.0.0.hbs`](../../../templates/weak-copyleft/cpal-1.0/CPAL-1.0-1.0.0.hbs)
- Steward/status: Socialtext / OSI-approved; the "badgeware" copyleft.

## Grant, conditions, restrictions

- Grant: use, copy, modify, and distribute, royalty-free, with a contributor
  patent grant.
- Conditions: source availability for covered code; notices retained; the
  attribution badge — a defined logo or text — must remain visible in the user
  interface of derivative works.
- Restrictions: the UI attribution duty is the distinguishing restriction of
  this member; removing the badge is a license violation.

## Patent position

Express grant with retaliation.

## Adoption

Set `SPDX_LICENSE_IDENTIFIER` to `CPAL-1.0`. Choose it only when a UI
attribution badge is an intended product requirement. The template body is
byte-identical to the canonical text.
