# Eclipse Public License 2.0 (`EPL-2.0`)

Family: A — Open Source, weak copyleft (A2). Canon:
[license taxonomy canon](../README.md); family reference:
[weak-copyleft README](README.md).

- Template: [`templates/weak-copyleft/epl-2.0/EPL-2.0-1.0.0.hbs`](../../../templates/weak-copyleft/epl-2.0/EPL-2.0-1.0.0.hbs)
- Steward/status: Eclipse Foundation; OSI-approved; module-level copyleft.
  Version 1.0 is legacy, GPL-incompatible, and carries no template.

## Grant, conditions, restrictions

- Grant: use, reproduce, modify, and distribute the program, in source and
  object form, royalty-free.
- Conditions: source availability for the licensed modules on distribution;
  notices retained; modifications to the licensed content remain under the
  EPL.
- Restrictions: the copyleft is module-scoped; separate modules under
  different terms may accompany the program.

## Patent position

Express grant with retaliation.

## Compatibility

GPL-compatible only when the Secondary Licenses notice is present; without it
the EPL-2.0 remains GPL-incompatible. Answered from the canonical
compatibility matrix.

## Adoption

Set `SPDX_LICENSE_IDENTIFIER` to `EPL-2.0`. The template body is
byte-identical to the canonical text.
