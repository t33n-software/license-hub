# Mozilla Public License 2.0 (`MPL-2.0`)

Family: A — Open Source, weak copyleft (A2). Canon:
[license taxonomy canon](../README.md); family reference:
[weak-copyleft README](README.md).

- Template: [`templates/weak-copyleft/mpl-2.0/MPL-2.0-1.0.0.hbs`](../../../templates/weak-copyleft/mpl-2.0/MPL-2.0-1.0.0.hbs)
- Steward/status: Mozilla Foundation; OSI-approved; the reference file-level
  copyleft. Version 1.1 is legacy and carries no template.

## Grant, conditions, restrictions

- Grant: use, copy, modify, and distribute, in source or executable form,
  royalty-free, with an express copyright and patent license from every
  contributor.
- Conditions: source form of covered files must remain under the MPL with
  source availability; modifications must be marked; license notices retained.
- Restrictions: the copyleft is file-scoped — new files may carry other terms;
  larger works may combine under different terms for the non-covered files.

## Patent position

Express grant with retaliation (patent litigation terminates the grant).

## Compatibility

Compatible with the GPL family unless a file carries the Exhibit B notice
("Incompatible With Secondary Licenses"), which removes GPL compatibility.
Answered from the canonical compatibility matrix.

## Adoption

Set `SPDX_LICENSE_IDENTIFIER` to `MPL-2.0`. The template body is
byte-identical to the canonical text.
