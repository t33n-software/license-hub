# European Union Public Licence 1.2 (`EUPL-1.2`)

Family: A — Open Source, weak copyleft (A2) with a network clause. Canon:
[license taxonomy canon](../README.md); family reference:
[weak-copyleft README](README.md).

- Template: [`templates/weak-copyleft/eupl-1.2/EUPL-1.2-1.0.0.hbs`](../../../templates/weak-copyleft/eupl-1.2/EUPL-1.2-1.0.0.hbs)
- Steward/status: European Commission; OSI-approved; published in 23 official
  EU languages with equal legal effect. Versions 1.0 and 1.1 are legacy and
  carry no template.

## Grant, conditions, restrictions

- Grant: use, reproduce, modify, and distribute the work, royalty-free.
- Conditions: copyleft on the work and its derivatives; source availability;
  notices retained.
- Restrictions: "communication to the public" includes software-as-a-service
  use, so the EUPL-1.2 closes the SaaS loophole inside a weak-copyleft frame.

## Patent position

Express grant (with the EUPL termination machinery).

## Compatibility

The appendix explicitly declares compatibility with GPL, AGPL, LGPL, MPL, EPL,
OSL, and CeCILL — combinations flow into those licenses as the appendix
directs. Answered from the canonical compatibility matrix.

## Adoption

Set `SPDX_LICENSE_IDENTIFIER` to `EUPL-1.2`. The template body is
byte-identical to the canonical text. For EU-centric public-sector or
EU-law-aligned projects this is the reference weak-copyleft-with-network
choice.
