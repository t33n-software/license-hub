# Open Software License 3.0 (`OSL-3.0`)

Family: A — Open Source, strong copyleft (A3). Canon:
[license taxonomy canon](../README.md); family reference:
[strong-copyleft README](README.md).

- Template: [`templates/strong-copyleft/osl-3.0/OSL-3.0-1.0.0.hbs`](../../../templates/strong-copyleft/osl-3.0/OSL-3.0-1.0.0.hbs)
- Steward/status: Lawrence Rosen; OSI-approved; a contract-style strong
  copyleft drafted for enforceability clarity. Versions 1.0 and 2.1 are legacy
  and carry no template.

## Grant, conditions, restrictions

- Grant: use, copy, modify, and distribute the work, with an express copyright
  and patent license.
- Conditions: derivative works must be licensed under the OSL-3.0 with source
  availability; notices retained.
- Restrictions: "external deployment" — offering the work as a network
  service — triggers the copyleft, which places this member on the network
  axis as well; its dominant class remains strong copyleft.

## Patent position

Express grant with retaliation.
