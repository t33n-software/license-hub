# Licence Art Libre 1.3 (`LAL-1.3`)

Family: F — Non-Software, F1 (Content and Documentation — free art). Canon:
[license taxonomy canon](../README.md); family reference:
[non-software README](README.md).

- Template: [`templates/non-software/lal-1.3/LAL-1.3-1.0.0.hbs`](../../../templates/non-software/lal-1.3/LAL-1.3-1.0.0.hbs)
- Steward/status: Copyleft Attitude; the free-art license. Version 1.2 is
  legacy and carries no template.

## Grant, conditions, restrictions

- Grant: copy, distribute, exhibit, and modify the artwork, for any purpose.
- Conditions: share-alike — derivative works carry the same license;
  attribution and license indication; access to the source form of the work.
- Restrictions: the art copyleft follows the work.

## Patent position

No grant (patent-silent).

## Adoption

Set `SPDX_LICENSE_IDENTIFIER` to `LAL-1.3`. The template body is
byte-identical to the canonical text.
