# Computational Use of Data Agreement 1.0 (`C-UDA-1.0`)

Family: F — Non-Software, F2 (Data and Databases — AI training data). Canon:
[license taxonomy canon](../README.md); family reference:
[non-software README](README.md).

- Template: [`templates/non-software/c-uda-1.0/C-UDA-1.0-1.0.0.hbs`](../../../templates/non-software/c-uda-1.0/C-UDA-1.0-1.0.0.hbs)
- Steward/status: Linux Foundation; the instrument for data sets intended for
  computational use, including AI/ML training.

## Grant, conditions, restrictions

- Grant: use, copy, modify, and distribute the data, including computational
  use for training models.
- Conditions: attribution and notice retention; the agreement scopes the
  computational-use permission explicitly.
- Restrictions: the grant covers the data; models trained on the data are
  addressed by the agreement's own terms — read them before redistribution of
  derived models.

## Patent position

No grant (patent-silent).
