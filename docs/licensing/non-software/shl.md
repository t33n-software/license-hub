# Solderpad Hardware License (`SHL-2.0`, `SHL-2.1`)

Family: F — Non-Software, F3 (Open Hardware). Canon:
[license taxonomy canon](../README.md); family reference:
[non-software README](README.md).

The Solderpad Hardware License is a permissive-leaning open-hardware license
line built on the Apache-2.0 drafting model, adapted to hardware designs.

## SHL-2.0 (`SHL-2.0`)

- Template: [`templates/non-software/shl-2.0/SHL-2.0-1.0.0.hbs`](../../../templates/non-software/shl-2.0/SHL-2.0-1.0.0.hbs)
- Grant: use, copy, modify, and distribute the design and artifacts produced
  from it, with an Apache-2.0-style copyright and patent grant.
- Conditions: notices retained; modifications marked.
- Adoption: set `SPDX_LICENSE_IDENTIFIER` to `SHL-2.0`.

## SHL-2.1 (`SHL-2.1`)

- Template: [`templates/non-software/shl-2.1/SHL-2.1-1.0.0.hbs`](../../../templates/non-software/shl-2.1/SHL-2.1-1.0.0.hbs)
- The 2.1 update: clarifies the rights-owner definitions ("copyright owner"
  reads as "rights owner") and the artifact coverage.
- Adoption: set `SPDX_LICENSE_IDENTIFIER` to `SHL-2.1`. The template body is
  byte-identical to the canonical text; its appendix keeps its bracketed
  how-to-apply placeholder instructions verbatim because they describe the
  per-file notice a tenant adds — they are not render anchors.

## Shared notes

- Patent position: express grant with retaliation (Apache-2.0 model).
- Both template bodies are byte-identical to their canonical texts.
