# GNU Free Documentation License 1.3 (`GFDL-1.3-only`, `GFDL-1.3-or-later`)

Family: F — Non-Software, F1 (Content and Documentation). Canon:
[license taxonomy canon](../README.md); family reference:
[non-software README](README.md).

- Template: [`templates/non-software/gfdl-1.3/GFDL-1.3-1.0.0.hbs`](../../../templates/non-software/gfdl-1.3/GFDL-1.3-1.0.0.hbs)
- Steward/status: Free Software Foundation; the documentation copyleft for
  manuals and textbooks. Versions 1.1 and 1.2 are legacy and carry no
  template.

## Grant, conditions, restrictions

- Grant: copy, modify, and distribute the document, in any medium.
- Conditions: the license text accompanies copies; modifications produce a
  document under the same license; invariant sections (when declared) must be
  preserved unmodified.
- Restrictions: documentation copyleft with invariant-section semantics;
  technical measures that restrict further copying are forbidden.

## Patent position

No grant (patent-silent).

## Adoption

Set `SPDX_LICENSE_IDENTIFIER` to `GFDL-1.3-only` or `GFDL-1.3-or-later` — the
text is shared and the suffix is the tenant's notice decision. Declare whether
invariant sections exist in the adopting document. The template body is
byte-identical to the canonical text; its how-to-use section keeps its
placeholder instructions verbatim.
