# Etalab Open License 2.0 (`etalab-2.0`)

Family: F — Non-Software, F2 (Data and Databases — French government data).
Canon: [license taxonomy canon](../README.md); family reference:
[non-software README](README.md).

- Template: [`templates/non-software/etalab-2.0/etalab-2.0-1.0.0.hbs`](../../../templates/non-software/etalab-2.0/etalab-2.0-1.0.0.hbs)
- Steward/status: Etalab (French government); the French open-data license,
  drafted in French and English for French and EU law.

## Grant, conditions, restrictions

- Grant: use, copy, modify, and distribute the data, including commercially,
  worldwide and royalty-free.
- Conditions: attribution — credit the data producer and the source,
  including the date of the last update.
- Restrictions: none beyond attribution; the license is compatible with the
  Open Government Licence and CC-BY-style attribution licenses.

## Patent position

No grant (patent-silent).

## Adoption

Set `SPDX_LICENSE_IDENTIFIER` to `etalab-2.0` — note the lowercase
identifier. The template body is byte-identical to the canonical text.
