# TAPR Open Hardware License 1.0 (`TAPR-OHL-1.0`)

Family: F — Non-Software, F3 (Open Hardware). Canon:
[license taxonomy canon](../README.md); family reference:
[non-software README](README.md).

- Template: [`templates/non-software/tapr-ohl-1.0/TAPR-OHL-1.0-1.0.0.hbs`](../../../templates/non-software/tapr-ohl-1.0/TAPR-OHL-1.0-1.0.0.hbs)
- Steward/status: TAPR; one of the foundational open-hardware licenses,
  covering documentation and physical artifacts.

## Grant, conditions, restrictions

- Grant: use, copy, modify, and distribute the documentation and the hardware
  designs, including manufacture of the physical artifact.
- Conditions: distributions of documentation or products carry the license
  and attribution; modified documentation remains under the license.
- Restrictions: the license addresses both the documentation and the
  artifacts produced from it — read the manufacture clauses before commercial
  production.

## Patent position

No express grant (patent-silent).

## Adoption

Set `SPDX_LICENSE_IDENTIFIER` to `TAPR-OHL-1.0`. For new hardware projects
prefer the CERN-OHL v2 family ([cern-ohl.md](cern-ohl.md)); TAPR remains for
continuity with existing TAPR projects. The template body is byte-identical
to the canonical text.
