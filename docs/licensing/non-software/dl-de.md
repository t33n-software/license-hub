# Data Licence Germany (`DL-DE-BY-2.0`, `DL-DE-ZERO-2.0`)

Family: F — Non-Software, F2 (Data and Databases — German government data).
Canon: [license taxonomy canon](../README.md); family reference:
[non-software README](README.md).

The Data Licence Germany family is the German federal government data license
line, drafted for German and EU law.

## DL-DE-BY-2.0 (`DL-DE-BY-2.0`)

- Template: [`templates/non-software/dl-de-by-2.0/DL-DE-BY-2.0-1.0.0.hbs`](../../../templates/non-software/dl-de-by-2.0/DL-DE-BY-2.0-1.0.0.hbs)
- Attribution variant: use, copy, modify, and distribute the data for any
  purpose, with attribution to the data provider.
- Adoption: set `SPDX_LICENSE_IDENTIFIER` to `DL-DE-BY-2.0`.

## DL-DE-ZERO-2.0 (`DL-DE-ZERO-2.0`)

- Template: [`templates/non-software/dl-de-zero-2.0/DL-DE-ZERO-2.0-1.0.0.hbs`](../../../templates/non-software/dl-de-zero-2.0/DL-DE-ZERO-2.0-1.0.0.hbs)
- Zero-conditions variant: use, copy, modify, and distribute the data for any
  purpose without conditions — the public-domain-equivalent of the family.
- Adoption: set `SPDX_LICENSE_IDENTIFIER` to `DL-DE-ZERO-2.0`.

## Shared notes

- Patent position: no grant (patent-silent) for both.
- Both template bodies are byte-identical to their canonical texts.
