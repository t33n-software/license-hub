# Open Database License 1.0 (`ODbL-1.0`)

Family: F — Non-Software, F2 (Data and Databases). Canon:
[license taxonomy canon](../README.md); family reference:
[non-software README](README.md).

- Template: [`templates/non-software/odbl-1.0/ODbL-1.0-1.0.0.hbs`](../../../templates/non-software/odbl-1.0/ODbL-1.0-1.0.0.hbs)
- Steward/status: Open Data Commons; the copyleft license for databases —
  the OpenStreetMap instrument.

## Grant, conditions, restrictions

- Grant: use, copy, modify, and distribute the database and its contents.
- Conditions: share-alike — public use or distribution of the database or a
  derivative database requires the same license, attribution, and access to
  the machine-readable form; produced works carry an attribution and a
  share-alike notice for the underlying database.
- Restrictions: the database copyleft follows the database, including
  publicly accessible services built on it.

## Patent position

No grant (patent-silent).

## Adoption

Set `SPDX_LICENSE_IDENTIFIER` to `ODbL-1.0`. Never mix ODbL data into
proprietary databases without a share-alike analysis. The template body is
byte-identical to the canonical text.
