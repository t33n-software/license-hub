# Public Domain Dedication and License 1.0 (`PDDL-1.0`)

Family: F — Non-Software, F2 (Data and Databases). Canon:
[license taxonomy canon](../README.md); family reference:
[non-software README](README.md).

- Template: [`templates/non-software/pddl-1.0/PDDL-1.0-1.0.0.hbs`](../../../templates/non-software/pddl-1.0/PDDL-1.0-1.0.0.hbs)
- Steward/status: Open Data Commons; the public-domain-equivalent instrument
  for data and databases.

## Instrument mechanics

- **Dedication:** the licensor waives copyright and database rights in the
  database to the fullest extent permitted by law.
- **Fallback license:** where the waiver is ineffective, a permissive license
  to use, copy, modify, and distribute for any purpose takes its place.
- **Disclaimer:** the database is provided as-is.

## Patent position

No grant (silent).

## Adoption

Set `SPDX_LICENSE_IDENTIFIER` to `PDDL-1.0`. The template body is
byte-identical to the canonical text. The same dedication-versus-license
distinction as in
[../../public-domain-dedication/README.md](../../public-domain-dedication/README.md)
applies to data.
