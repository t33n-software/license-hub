# Open Data Commons Attribution 1.0 (`ODC-By-1.0`)

Family: F — Non-Software, F2 (Data and Databases). Canon:
[license taxonomy canon](../README.md); family reference:
[non-software README](README.md).

- Template: [`templates/non-software/odc-by-1.0/ODC-By-1.0-1.0.0.hbs`](../../../templates/non-software/odc-by-1.0/ODC-By-1.0-1.0.0.hbs)
- Steward/status: Open Data Commons; the attribution license for databases.

## Grant, conditions, restrictions

- Grant: use, copy, modify, and distribute the database and its contents,
  including commercially.
- Conditions: attribution — every public use, distribution, or produced work
  carries a notice identifying the database and its licensor.
- Restrictions: none beyond attribution; no share-alike duty.

## Patent position

No grant (patent-silent).

## Adoption

Set `SPDX_LICENSE_IDENTIFIER` to `ODC-By-1.0` — note the exact casing of the
identifier. The template body is byte-identical to the canonical text.
