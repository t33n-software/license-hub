# Community Data License Agreements (CDLA)

Family: F — Non-Software, F2 (Data and Databases). Canon:
[license taxonomy canon](../README.md); family reference:
[non-software README](README.md).

The Linux Foundation data license family. All three referenced members carry
templates.

## CDLA-Permissive-1.0 (`CDLA-Permissive-1.0`)

- Template: [`templates/non-software/cdla-permissive-1.0/CDLA-Permissive-1.0-1.0.0.hbs`](../../../templates/non-software/cdla-permissive-1.0/CDLA-Permissive-1.0-1.0.0.hbs)
- The first permissive data release: use, modify, and share the data with
  attribution; no share-alike duty.
- Adoption: set `SPDX_LICENSE_IDENTIFIER` to `CDLA-Permissive-1.0`.

## CDLA-Permissive-2.0 (`CDLA-Permissive-2.0`)

- Template: [`templates/non-software/cdla-permissive-2.0/CDLA-Permissive-2.0-1.0.0.hbs`](../../../templates/non-software/cdla-permissive-2.0/CDLA-Permissive-2.0-1.0.0.hbs)
- The current permissive release: the same permissive grant with clarified
  scope and attribution mechanics; the preferred permissive data choice.
- Adoption: set `SPDX_LICENSE_IDENTIFIER` to `CDLA-Permissive-2.0`.

## CDLA-Sharing-1.0 (`CDLA-Sharing-1.0`)

- Template: [`templates/non-software/cdla-sharing-1.0/CDLA-Sharing-1.0-1.0.0.hbs`](../../../templates/non-software/cdla-sharing-1.0/CDLA-Sharing-1.0-1.0.0.hbs)
- The data copyleft: modifications and additions to the data must be shared
  under the same license, with attribution.
- Adoption: set `SPDX_LICENSE_IDENTIFIER` to `CDLA-Sharing-1.0`. Treat it with
  the same combination analysis duty as software copyleft.

## Shared notes

- Patent position: no grant (patent-silent) for all three.
- All three template bodies are byte-identical to their canonical texts.
