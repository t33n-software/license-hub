# IPA Font License (`IPA`)

Family: F — Non-Software, F4 (Fonts). Canon:
[license taxonomy canon](../README.md); family reference:
[non-software README](README.md).

- Template: [`templates/non-software/ipa/IPA-1.0.0.hbs`](../../../templates/non-software/ipa/IPA-1.0.0.hbs)
- Steward/status: Information-technology Promotion Agency, Japan; the license
  of the IPA font family, OSI-approved.

## Grant, conditions, restrictions

- Grant: use, copy, modify, and distribute the font software, including
  embedding in documents and products.
- Conditions: modified versions must be distributed under a different font
  name; the license text and copyright notices accompany distributions.
- Restrictions: no standalone sale of the font; derived fonts keep the
  license; the original font name is reserved for the unmodified original.

## Patent position

No grant (patent-silent).

## Adoption

Set `SPDX_LICENSE_IDENTIFIER` to `IPA`. The template body is byte-identical
to the canonical text.
