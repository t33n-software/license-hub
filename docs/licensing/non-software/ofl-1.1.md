# SIL Open Font License 1.1 (`OFL-1.1`)

Family: F — Non-Software, F4 (Fonts). Canon:
[license taxonomy canon](../README.md); family reference:
[non-software README](README.md).

- Template: [`templates/non-software/ofl-1.1/OFL-1.1-1.0.0.hbs`](../../../templates/non-software/ofl-1.1/OFL-1.1-1.0.0.hbs)
- Steward/status: SIL International; the reference font license. Version 1.0
  is legacy and carries no template.

## Grant, conditions, restrictions

- Grant: use, study, copy, merge, embed, modify, and redistribute the font
  software, including in documents and products.
- Conditions: modified versions must not use a Reserved Font Name without
  explicit written permission; the license text accompanies the font;
  modified versions remain under the OFL.
- Restrictions: the font software must not be sold standalone; the reserved
  font names mechanism protects the original font identity.

## Patent position

No grant (patent-silent).

## Adoption

Set `SPDX_LICENSE_IDENTIFIER` to `OFL-1.1`. The license body is fixed; the
copyright line and any Reserved Font Name declaration live in the font's
copyright/header files, not in the license text — the template therefore
carries the verbatim body and the tenant declares the font copyright line in
its source headers. Never distribute an OFL font under a new name while
ignoring a declared Reserved Font Name.
