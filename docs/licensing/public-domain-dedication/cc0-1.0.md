# CC0 1.0 Universal (`CC0-1.0`)

Family: E — Public Domain Dedication. Canon:
[license taxonomy canon](../README.md); family reference:
[public-domain-dedication README](README.md).

- Template: [`templates/public-domain-dedication/cc0-1.0/CC0-1.0-1.0.0.hbs`](../../../templates/public-domain-dedication/cc0-1.0/CC0-1.0-1.0.0.hbs)
- Steward/status: Creative Commons; FSF-free and GPL-compatible; **not
  OSI-approved** (patent clause concerns; withdrawn from OSI review). CC0 is
  the only Creative Commons tool acceptable for code — every other CC license
  must not be used for software.

## Instrument mechanics

- **Waiver:** the affirmer overtly, fully, permanently, irrevocably, and
  unconditionally waives all copyright and related rights, in all
  territories, for the maximum legal duration, for any purpose including
  commercial ones.
- **Public license fallback:** where the waiver is judged invalid or
  ineffective, a royalty-free, non-transferable, non-sublicensable,
  non-exclusive, irrevocable license to exercise the same rights takes its
  place — this is the mechanism that keeps CC0 robust in no-waiver
  jurisdictions such as Germany and Austria.
- **Limitations:** no trademark or patent rights are waived or licensed.

## Patent position

Explicit non-grant — patents are expressly not licensed.

## Adoption

Set `SPDX_LICENSE_IDENTIFIER` to `CC0-1.0`. Prefer CC0 for content, data, and
documentation dedications; for code where patent silence must be avoided,
choose 0BSD or MIT-0 instead. The template body is byte-identical to the
canonical text.
