# WTFPL (`WTFPL`)

Family: E — Public Domain Dedication. Canon:
[license taxonomy canon](../README.md); family reference:
[public-domain-dedication README](README.md).

- Template: [`templates/public-domain-dedication/wtfpl/WTFPL-1.0.0.hbs`](../../../templates/public-domain-dedication/wtfpl/WTFPL-1.0.0.hbs)
- Steward/status: Sam Hocevar; version 2 (December 2004); FSF-free but **not
  OSI-approved**, and corporate policies often reject it.

## Instrument mechanics

- **Terms:** everyone is permitted to copy and distribute verbatim or modified
  copies of the license document, and changing it is allowed as long as the
  name is changed; for the covered work: "you just do what you want to."
- **Form:** an informal dedication-style text without a fallback license
  clause.

## Patent position

No grant (silent).

## Adoption

Set `SPDX_LICENSE_IDENTIFIER` to `WTFPL`. Verify corporate policy acceptance
before adopting; for EU-centric projects prefer 0BSD, which carries the same
practical effect with OSI approval and a fallback-safe form. The template body
is byte-identical to the canonical text; the steward document copyright line
("Copyright (C) 2004 Sam Hocevar") is part of the canonical license document
and stays verbatim — the tenant's own copyright is carried by the per-file
source headers.
