# Cryptographic Autonomy License 1.0 (`CAL-1.0`)

Family: A — Open Source, network copyleft (A4). Canon:
[license taxonomy canon](../README.md); family reference:
[network-copyleft README](README.md).

- Template: [`templates/network-copyleft/cal-1.0/CAL-1.0-1.0.0.hbs`](../../../templates/network-copyleft/cal-1.0/CAL-1.0-1.0.0.hbs)
- Steward/status: Holochain; OSI-approved; strong copyleft plus network use
  and a user-data access duty.

## Grant, conditions, restrictions

- Grant: use, copy, modify, and distribute the work, with an express copyright
  and patent license.
- Conditions: strong copyleft on derivatives; network use triggers source
  obligations; users of a hosted instance retain access to their data.
- Restrictions: the user-data portability duty is the distinguishing
  restriction of this member; a Combined Work Exception exists as a separate
  steward instrument and is not part of this template.

## Patent position

Express grant with retaliation.

## Adoption

Set `SPDX_LICENSE_IDENTIFIER` to `CAL-1.0`. Choose it only when user-data
portability is an intended obligation alongside the network copyleft. The
template body is byte-identical to the canonical text.
