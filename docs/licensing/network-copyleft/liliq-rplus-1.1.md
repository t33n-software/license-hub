# LiLiQ-Rplus 1.1 (`LiLiQ-Rplus-1.1`)

Family: A — Open Source, network copyleft (A4). Canon:
[license taxonomy canon](../README.md); family reference:
[network-copyleft README](README.md).

- Template: [`templates/network-copyleft/liliq-rplus-1.1/LiLiQ-Rplus-1.1-1.0.0.hbs`](../../../templates/network-copyleft/liliq-rplus-1.1/LiLiQ-Rplus-1.1-1.0.0.hbs)
- Steward/status: Government of Québec; OSI-approved; the reciprocal-forte
  member of the Licence Libre du Québec family — strong copyleft extended to
  network (SaaS) use.

## Grant, conditions, restrictions

- Grant: use, reproduce, modify, and distribute the software, royalty-free.
- Conditions: the LiLiQ-R reciprocity duties, extended so that providing the
  software as a network service also triggers source obligations.
- Restrictions: the network-scoped reciprocity follows the software; no
  trademark rights.

## Patent position

Express grant with retaliation, following the LiLiQ family patent clause.
