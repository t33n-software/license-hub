# GNU Affero General Public License v3.0 (`AGPL-3.0-only`, `AGPL-3.0-or-later`)

Family: A — Open Source, network copyleft (A4). Canon:
[license taxonomy canon](../README.md); family reference:
[network-copyleft README](README.md).

- Template: [`templates/network-copyleft/agpl-3.0/AGPL-3.0-1.0.0.hbs`](../../../templates/network-copyleft/agpl-3.0/AGPL-3.0-1.0.0.hbs)
- Steward/status: Free Software Foundation; OSI-approved; the reference
  network copyleft. AGPL v1.0 is legacy and carries no template.

## Grant, conditions, restrictions

- Grant: the GPLv3 grant.
- Conditions: the GPLv3 strong-copyleft duties, plus §13 — users interacting
  with the program over a network must be able to receive the corresponding
  source.
- Restrictions: GPLv3 restrictions apply, including anti-tivoization and the
  cure period.

## Patent position

Express grant with retaliation through the GPLv3 base (§11).

## Compatibility

Linkable with GPL-3.0 both ways via the §13 clauses; a combined network work
stays AGPL. Answered from the canonical compatibility matrix.

## Adoption

Set `SPDX_LICENSE_IDENTIFIER` to `AGPL-3.0-only` or `AGPL-3.0-or-later` — the
text is shared and the suffix is the tenant's notice decision. Choose AGPL-3.0
when the software will be offered as a network service and community source
protection is the goal. The template body is byte-identical to the canonical
text; its how-to-apply section keeps its placeholder instructions verbatim.
