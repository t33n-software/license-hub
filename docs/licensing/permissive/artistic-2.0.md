# Artistic License 2.0 (`Artistic-2.0`)

Family: A — Open Source, permissive (A1). Canon:
[license taxonomy canon](../README.md); family reference:
[permissive README](README.md).

- Template: [`templates/permissive/artistic-2.0/Artistic-2.0-1.0.0.hbs`](../../../templates/permissive/artistic-2.0/Artistic-2.0-1.0.0.hbs)
- Steward/status: The Perl Foundation; OSI-approved. Version 2.0 resolves the
  ambiguities of Artistic 1.0, which is legacy and must not be adopted for new
  code.

## Grant, conditions, restrictions

- Grant: copy, modify, and distribute the Package, with artistic control
  retained by the Copyright Holder over the Standard Version.
- Conditions: modified versions must document the changes; distribution of a
  Modified Version follows one of the defined paths (Standard Version access,
  public offer of the Standard Version, or renaming plus documentation).
- Restrictions: no trademark rights; the Standard Version's integrity is
  protected by the modification paths.

## Patent position

Express grant with retaliation — the license terminates for a licensee who
institutes patent litigation alleging the Package infringes a patent.

## Adoption

Set `SPDX_LICENSE_IDENTIFIER` to `Artistic-2.0`. The template body is
byte-identical to the canonical text.
