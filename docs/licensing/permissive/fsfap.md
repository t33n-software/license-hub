# FSF All Permissive License (`FSFAP`)

Family: A — Open Source, permissive (A1). Canon:
[license taxonomy canon](../README.md); family reference:
[permissive README](README.md).

- Template: [`templates/permissive/fsfap/FSFAP-1.0.0.hbs`](../../../templates/permissive/fsfap/FSFAP-1.0.0.hbs)
- Steward/status: Free Software Foundation; a one-paragraph all-permissive
  notice intended for small files, build scripts, and supporting material.

## Grant, conditions, restrictions

- Grant: copying and distribution of the file, with or without modification,
  in any medium, without royalty.
- Conditions: the copyright notice and the license notice must be preserved.
- Restrictions: none beyond preservation; the file is offered as-is without
  any warranty.

## Patent position

No grant.

## Adoption

Set `SPDX_LICENSE_IDENTIFIER` to `FSFAP`. The canonical text references a
copyright notice without carrying one, so the template prepends the anchored
`COPYRIGHT_YEAR` and `COPYRIGHT_HOLDER` line ahead of the verbatim text.
