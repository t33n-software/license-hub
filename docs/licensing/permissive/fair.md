# Fair License (`Fair`)

Family: A — Open Source, permissive (A1). Canon:
[license taxonomy canon](../README.md); family reference:
[permissive README](README.md).

- Template: [`templates/permissive/fair/Fair-1.0.0.hbs`](../../../templates/permissive/fair/Fair-1.0.0.hbs)
- Steward/status: OSI-approved; an ultra-short permissive instrument.

## Grant, conditions, restrictions

- Grant: usage of the works for any purpose.
- Conditions: the instrument must be retained with the works so that any
  using entity is notified of it.
- Restrictions: none beyond retention; the works are without warranty.

## Patent position

No grant.

## Adoption

Set `SPDX_LICENSE_IDENTIFIER` to `Fair`. The template anchors the
`<Copyright Information>` slot of the canonical text to the `COPYRIGHT_YEAR`
and `COPYRIGHT_HOLDER` anchors.
