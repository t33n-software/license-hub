# ISC License (`ISC`)

Family: A — Open Source, permissive (A1). Canon:
[license taxonomy canon](../README.md); family reference:
[permissive README](README.md).

- Template: [`templates/permissive/isc/ISC-1.0.0.hbs`](../../../templates/permissive/isc/ISC-1.0.0.hbs)
- Steward/status: Internet Systems Consortium / OpenBSD; OSI-approved;
  functionally equivalent to MIT with leaner wording.

## Grant, conditions, restrictions

- Grant: use, copy, modify, and distribute for any purpose, with or without
  fee.
- Conditions: the copyright notice and the permission notice must appear in
  all copies.
- Restrictions: none beyond the notice condition; full warranty disclaimer and
  liability exclusion.

## Patent position

No grant.

## Adoption

Set `SPDX_LICENSE_IDENTIFIER` to `ISC`. The steward-published text carries the
steward's own copyright lines; the template replaces them with the anchored
`COPYRIGHT_YEAR` and `COPYRIGHT_HOLDER` line, which is the standard adoption
form of this license.
