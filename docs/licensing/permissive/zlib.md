# zlib License (`Zlib`)

Family: A — Open Source, permissive (A1). Canon:
[license taxonomy canon](../README.md); family reference:
[permissive README](README.md).

- Template: [`templates/permissive/zlib/Zlib-1.0.0.hbs`](../../../templates/permissive/zlib/Zlib-1.0.0.hbs)
- Steward/status: zlib project; OSI-approved; widely used for small libraries
  and game-adjacent tooling.

## Grant, conditions, restrictions

- Grant: use for any purpose, including commercial applications; alteration
  and free redistribution.
- Conditions: none in the notice-retention sense; the license text itself must
  remain unaltered in source distributions.
- Restrictions: the origin of the software must not be misrepresented — no
  claiming authorship of the original; altered source versions must be plainly
  marked as altered.

## Patent position

No grant.

## Adoption

Set `SPDX_LICENSE_IDENTIFIER` to `Zlib`. The canonical text references no
embedded copyright line, so the template prepends the anchored
`COPYRIGHT_YEAR` and `COPYRIGHT_HOLDER` line ahead of the verbatim text.
